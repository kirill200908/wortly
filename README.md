# Wortly — немецкий каждый день

Личный словарь и короткие игровые тренировки с русским интерфейсом.

Проверка строгая: правильным считается только весь текст вашей сохранённой пары. Игнорируются лишь пробелы по краям ответа. Регистр, ё/е, ä/ae, ß/ss, пунктуация и пробелы внутри различаются. Знаки `/`, `;` и другие символы внутри перевода — часть текста, а не список допустимых ответов. Например, для сохранённого `учить / изучать` нужно ввести всю строку. Поиск слов остаётся нечувствительным к регистру, но это не меняет правила проверки.

Чтобы одинаковая подсказка с разными переводами не требовала угадать задуманный вариант, в один подход попадает только одна такая пара. Выбор делается после приоритизации повторений, поэтому другие сохранённые переводы могут появиться в следующем подходе. Словарь при этом не меняется.

- Добавление и редактирование слов, наборы, поиск и фильтры.
- Вставка списка или импорт TXT, CSV, TSV. Например: `das Haus — дом`.
- Карточки, выбор перевода, ввод ответа и поиск пар.
- Обратное направление: русский → немецкий.
- Озвучка немецких слов через голос браузера, если он доступен.
- История ответов, точность, серии занятий, сложные слова и интервальное повторение.
- Резервная копия JSON со словарём и историей, восстановление на другом устройстве.
- Адаптивный интерфейс для телефона и компьютера.

## Как считается прогресс

Новые слова имеют уровень 0. Верный ответ повышает уровень не чаще одного раза в 4 часа, ранние повторы не отодвигают назначенную дату. После повышения следующее повторение назначается через 10 минут, 1 день, 3 дня, 7 дней или 21 день. Ошибка снижает уровень и возвращает слово на повторение через 10 минут. Уровни 4 и 5 отмечаются как «Выучено». Самооценка в карточках тоже засчитывается.

Это прозрачная оценка по ответам, а не научная диагностика памяти. Данные хранятся только в localStorage этого браузера: автоматической синхронизации и регистрации нет. Смена устройства, браузера или очистка данных требует восстановления из резервной копии.

## Запуск

Статический сайт без сборки и зависимостей. Запустите любой локальный HTTP-сервер в папке с `index.html`. Для публикации включите **Settings → Pages → Deploy from a branch → main → / (root)**. Файл `.nojekyll` отключает обработку Jekyll.

## Проверки

Node.js 18 или новее:

```sh
node --check app.js
node --check core.js
node --test tests/core.test.cjs
```

Используются только браузерные API. Google Fonts необязательны: без сети интерфейс использует системные шрифты.
